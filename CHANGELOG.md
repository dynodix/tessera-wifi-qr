# Changelog

## 0.2.0
- A second tile, **QR code**: a QR code of any text, such as a link. It shows the state of the tile's entity (a
  template sensor or a text helper, up to 160 bytes), so Home Assistant decides what it holds and a new value needs no
  build, or the text typed in its inspector (up to 64 characters) where the tile has no entity. An optional caption
  stands under the code.

## 0.1.1 - 2026-10-24
- The tile can now be resized from 1 x 1 through 3 x 3 in Layout.

## 0.1.0
- First version: a scannable WPA Wi-Fi QR code driven by two Home Assistant Text helpers.
